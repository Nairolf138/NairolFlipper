# Contribuer à NairolFlipper

Lire `AGENTS.md`, `docs/INDEX.md`, `docs/CODING_STANDARDS.md`, `docs/DEFINITION_OF_DONE.md` et `docs/ASSET_LEGAL_POLICY.md` avant contribution.

Une pull request doit résoudre une intention claire, rester petite, inclure les tests pertinents, préserver les plateformes cibles et documenter toute décision durable.

## Branches

```text
feat/nom-court
fix/nom-court
docs/nom-court
refactor/nom-court
chore/nom-court
```

## Commits

```text
feat: add bumper scoring
fix: prevent ball tunneling through drain wall
docs: clarify showflow phases
test: add score manager regression test
```

Tout asset ajouté doit avoir une origine, une licence et une autorisation compatible avec la distribution du jeu.
