# Placeholder music stems

These eight synchronized 120 BPM / 16-beat loops are original synthesized
placeholders generated by `tools/generate_placeholder_music.py`. They contain no
third-party samples and are dedicated to the public domain under CC0-1.0.

All files have the same duration and start point so they can be layered by the
Godot music transport. They intentionally favor clarity and small downloads over
final-production sound quality.
