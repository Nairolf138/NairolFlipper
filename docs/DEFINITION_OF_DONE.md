# Definition of Done

## Fonctionnel

- [ ] comportement demandé présent
- [ ] cas limites évidents traités
- [ ] pas de grosse feature non demandée

## Technique

- [ ] projet Godot importable
- [ ] pas d'erreur bloquante
- [ ] code conforme
- [ ] tuning modifiable
- [ ] aucun secret
- [ ] aucune dépendance injustifiée

## Tests

- [ ] tests pertinents
- [ ] smoke test
- [ ] build plateforme concernée
- [ ] test de régression si bug

## Cross-platform

- [ ] clavier/tactile/manette considérés
- [ ] Web considéré
- [ ] pas d'API OS non abstraite

## Design

- [ ] feedback compréhensible
- [ ] accessibilité considérée
- [ ] vision respectée

## Documentation

- [ ] docs/backlog/roadmap/changelog mis à jour si nécessaire

Une tâche de feel n'est jamais pleinement validée sans playtest humain sur au moins une plateforme cible.
