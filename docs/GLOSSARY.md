# Glossaire canonique

- **NairolFlipper** : nom du jeu.
- **Show** : séquence audiovisuelle construite pendant une partie.
- **Showflow** : progression dramaturgique globale.
- **Rig** : ensemble des familles lumineuses progressées.
- **Fixture Family** : Face, Wash, Beam, Gobo, Strobe, Blinder.
- **Cue** : étape de conduite structurée.
- **Cue Stack** : suite de cues.
- **Flow** : multiplicateur d'enchaînement.
- **Sync Bonus** : bonus facultatif près du pulse.
- **Final Show** : climax principal/multiball.
- **Blackout** : conclusion visuelle.
- **Safety** : nom thématique du Ball Save.
- **Aftershow Replay** : post-MVP, résumé d'événements de partie.
- **Standby / Preset / Build / Flow / Break / Final / Encore** : états narratifs du Showflow.
