# Confidentialité et modèle économique

## Modèle économique

Jeu gratuit, pas de pay-to-win, pas de publicité intrusive, pas de dark patterns. Possibles plus tard : dons, GitHub Sponsors, Ko-fi, soundtrack, soutien volontaire.

## Données

MVP local-first. Aucun besoin de compte, email, localisation, tracking publicitaire ou analytics réseau.

## Télémétrie

Aucune par défaut. Si ajout futur : opt-in, finalité claire, données minimales, documentation, jeu possible sans.

## Leaderboards

Post-MVP. Ils nécessitent anti-triche, identifiants, modération, vie privée et coûts backend, sans jamais bloquer le local.
