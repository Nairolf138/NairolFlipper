# ADR-0001 — Godot 4.7.2 stable

Status: Accepted

## Context

NairolFlipper doit être gratuit, open source, 2D, automatisable et exportable vers Web, Android, iOS et desktop.

## Decision

Utiliser **Godot 4.7.2 stable** comme version de référence initiale et l'épingler en CI.

## Consequences

Format connu, exports multiplateformes, pas de migration automatique vers dev/beta.
