# ADR-0002 — GDScript uniquement

Status: Accepted

## Context

Le Web est P0 et doit partager le même cœur de code.

## Decision

Gameplay et application utilisent **GDScript**. C# n'est pas autorisé initialement.

## Consequences

Chaîne plus simple, compatibilité Web privilégiée, tout autre langage exige une ADR.
