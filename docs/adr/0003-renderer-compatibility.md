# ADR-0003 — GL Compatibility par défaut

Status: Accepted

## Context

Le jeu doit fonctionner sur navigateurs et mobiles variés.

## Decision

Utiliser **GL Compatibility** par défaut avec fallbacks de qualité.

## Consequences

Portée matérielle accrue ; impact visuel obtenu par design/contraste/shaders compatibles plutôt que brute force GPU.
